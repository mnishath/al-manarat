# Al Manarat Heights Islamic School

Modern marketing site for Al Manarat Heights (Mississauga), featuring the new **AIR Lab** (Artificial Intelligence & Robotics Lab) pilot program.

## Stack

- Vite + React + TypeScript
- React Router
- Brand assets & faculty photos from [almanaratheights.com](https://almanaratheights.com)
- Generated photorealistic lab imagery for AIR Lab scenes

## Develop

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
npm run preview
```
